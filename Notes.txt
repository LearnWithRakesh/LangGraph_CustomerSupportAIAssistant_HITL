Why do we need a langGraph?
Let us consider an AI System, that processes a 5 Lakh rupees business loan application

It must vey the documents, 
Calucalte the eligibility
Check fraud indicators, 
missing request information
Obtain human approval,
Retain a complete decision history

So here - Simple prompt-to-response application is not sufficient - 
because - It has multiple states, 
conditional branches, possible retries and if any Human dependencies



langGraph becomes valuable - 

1. What step is currently running?
2. What information has already been collected
3. which action should happen next?
4. Should the workflow repeat an earlier step?
5. can execution pause for several days
6. Can another worker resume the same case?
7. What happens when a node fails - do we have retry mechanism (fail - safe mechanism)
8. How can we prevent an action from being executed twice?
